Redesign frontend KanPOS memakai Shark UI

Semua frame di bawah memakai token dan anatomi komponen asli Shark UI (Ark UI + Tailwind v4). Skrol ke kanan untuk melihat semua layar. Frame terakhir adalah lembar token & komponen plus tabel perbandingan dengan design sekarang.

  • Yang berubah drastis: tidak ada lagi pil 24–26px dan blob ikon biru muda. Card jadi rounded-xl (12px) border 1px shadow tipis; tombol 8px; badge status pakai tint 10% + border 20%.
  • Font: Sora → Hanken Grotesk (font default Shark). Bobot heading turun dari extrabold ke semibold.
  • Header halaman: pil putih + ikon bulat diganti header polos 56px dengan judul kiri dan tombol ikon outline kanan (Shark tidak punya pill header).
  • Navigasi bawah: Bottom Navigation Shark (flat, border-top, blur). FAB Kasir dipertahankan tapi jadi kotak rounded-xl sesuai bahasa Shark.
  • Tab kelompok (Barang/Catatan): Tabs varian underline. Filter kategori/status: Segment Group.
  • Warna primary tetap #3554C1. Status pakai token Shark: success emerald, warning amber, destructive red, info blue.
