Yang berubah di tampilan

Sidebar bisa diciutkan ke rail 64pxIkon tetap, label hilang, badge jadi titik. Tabel jadi lebih lega di layar 13". Coba tombol "Rail" di bar atas.
Antrean kerja jadi halaman sendiriSekarang "Perlu ditangani" cuma kartu kecil di Ringkasan. Di v2, Ringkasan hanya menampilkan ringkasannya, dan halaman Antrean memuat daftarnya lengkap dengan tombol aksi per baris.
Detail pengguna dua kolomKolom kanan lengket: identitas, status, langganan, tombol aksi. Kolom kiri tab: Toko, Transaksi, Backup, Audit. Tidak perlu gulir jauh untuk "Beri langganan".
Filter jadi chip dengan hitunganChip "Segera habis (12)" langsung memberi tahu ada berapa, tanpa harus mengklik dulu.
Aksi baris muncul saat hoverRekonsiliasi, buka pengguna, salin ref: ada di ujung kanan baris. Tidak perlu klik masuk detail dulu.
Topbar lebih ringkasBreadcrumb, pencarian global (⌘K) yang mencari pengguna + ref Tripay sekaligus, indikator lingkungan (Produksi), tema, akun.
